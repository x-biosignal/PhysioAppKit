A small, domain-neutral engine for single-case (N-of-1) analysis shared
by physiological application layers (rehabilitation, sport,
psychophysiology, and others). Provides the Nonoverlap of All Pairs
(NAP) effect size, a threshold-and-band single-case analysis, a phase
plot, an honest hypothesis-to-evidence verdict combiner, and a
dependency-free Rasch model for turning ordinal ratings into an interval
scale. Application layers supply their domain slots (ontology,
threshold, goal, reasoning, report) and call this engine; the engine
knows nothing about any specific domain.
