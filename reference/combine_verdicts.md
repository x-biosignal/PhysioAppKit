# Combine per-item verdicts into an honest overall (supported/partial/refuted)

Combine per-item verdicts into an honest overall
(supported/partial/refuted)

## Usage

``` r
combine_verdicts(items)
```

## Arguments

- items:

  list of items, each with a \`\$supported\` field that is TRUE, FALSE
  or NA.

## Value

one of the Japanese overall labels.
